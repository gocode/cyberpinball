# EcranTelechargements

Téléchargements, borne 1080 × 1920. Tout ce que Cyber Pinball a téléchargé, du plus récent au plus ancien : nom et nature, d’où il vient, date, taille, puis à quoi il sert (installé, attendu, gardé de côté, sans usage) avec son mot et son signe. Une ligne ouvre le détail du fichier (le reprendre, le mettre à la corbeille) ; « Tout vider » passe par une confirmation qui dit ce qui reste attendu.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
