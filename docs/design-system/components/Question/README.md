# Question

Une question qui bloque l'écran : ce qui serait perdu, où l'on va, deux réponses, un délai visible. Le délai de cette maquette poursuit la configuration ; il ne valide jamais la sortie.

- Fournir : `.cp-scrim` > `.cp-dialog` avec un titre (la question), le contenu, `.choices` (deux `.cp-btn`, la réponse choisie en `.is-focus`), `.cp-timer` si la question se ferme seule.
- Cadre sarcelle et texte neutre ; la réponse choisie seule porte le vert signal.
- Toujours dire ce qui serait perdu et où l'on revient.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
