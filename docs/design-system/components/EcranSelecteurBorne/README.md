# EcranSelecteurBorne

Sélecteur de fichiers, borne 1080 × 1920 (playfield tourné), ouvert sur les téléchargements de Cyber Pinball filtrés pour un fronton. Les emplacements passent en bandeau en tête, chaque fichier dit d’où il vient et à quoi il sert déjà ; un seul choix : Start le prend.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
