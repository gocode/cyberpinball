# EcranMenuSysteme

Menu système, 1920 × 1080. Fond d’ambiance sans faux média ; huit fonctions existantes, version séparée du dernier choix et bandeau de commandes. La sélection est un aplat lisible jusqu’au dernier caractère.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
