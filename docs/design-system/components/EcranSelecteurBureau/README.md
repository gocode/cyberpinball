# EcranSelecteurBureau

Sélecteur de fichiers, bureau 1920 × 1080, à la place de la boîte de dialogue de Windows. Emplacements à gauche (téléchargements de Cyber Pinball d’abord, ceux de Windows, dossier d’import, Bureau, clés USB et disques), le dossier ouvert au centre, filtré sur ce qu’on attend, les gestes à droite. Deux fichiers choisis : le geste principal les prend.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
