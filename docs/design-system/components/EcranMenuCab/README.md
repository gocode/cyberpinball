# EcranMenuCab

Menu des tables, 1080 × 1920. Le repli « verre fumé » occupe le plateau. Le titre et la roue sont protégés par un fond opaque. Anneau choisi unique ; marque et métadonnées restent secondaires.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
