# EcranFiche

Fiche de table, 1920 × 1080. Colonne de médias à gauche ; panneau de lecture à droite. Les six onglets passent sur deux rangées pour conserver 20 px. Infos est ouvert, Jouer porte le focus ; aucun second anneau vert.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
