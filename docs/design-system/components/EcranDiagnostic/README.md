# EcranDiagnostic

Diagnostic, 1080 × 1920. Les constats sont groupés par gravité et gardent une largeur de lecture utile. Les états sont neutres, accompagnés de signes et de mots. Tout réparer est la seule action allumée.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
