# EcranParcours

Ce qu’il manque pour jouer, borne 1080 × 1920. La progression (étape n sur N, réglées, restantes) est en tête ; les étapes sont numérotées et gardent un mot et un signe ; la courante est dépliée avec ce qu’il faut savoir, et son geste principal est la seule action allumée. Les étapes réglées restent visibles, grisées et cochées.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
