# EcranAssistant

Assistant des boutons, 1920 × 1080. Consigne à gauche, six boutons obligatoires dans une colonne numérotée à droite ; trois boutons facultatifs sous un séparateur. Le bouton attendu est le seul contrôle sélectionné.

Aperçu statique, sans logique de navigation. Dimensions de référence en pixels pour petit côté 1080. Texte minimum 20 px. Règles communes : ../../README.md.
