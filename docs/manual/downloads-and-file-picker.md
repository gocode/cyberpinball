## Downloads and file picker

Everything Cyber Pinball downloads ends up under `<racine>\downloads`, sorted by origin: `acquisition\` (the "Récupérer" (Get) window, waiting list), `sites\<site>-<entry>\fichiers\` (community site media, recorded in `sites\recus.json`), `sites\web\…` (web search from a media item, `sites\web.json`), `vpinmediadb\` (VPinMediaDB files named after their MD5, deleted after a day), `cyberpinball\` (update installers) and, at the top, component archives (VPX), kept to reinstall offline.
Indexes (`vpsdb.json`, `vpinmdb.json`…), records, site thumbnails and downloads in progress are internal: neither listed nor emptied.

- **"Fichiers téléchargés" (Downloaded files) screen** (Menu système (System menu) > Téléchargements (Downloads) > "Fichiers téléchargés"): each file, newest first (then by name or by size), with its kind (table, backglass, ROM, image, video, archive, installer), where it came from (site, "Récupérer", site media, web search, VPinMediaDB, update), its date, its size, and what it is for, with a word and a sign: **✓ Installed with** <table>, **!
  To install** (received by the waiting list, not installed yet), **○ Kept aside**, **i Received for** <media> (sites, web, VPinMediaDB), **✓** what was done with it when it was reused through the picker (log `downloads\journal.json`), **○ No known use**.
  A file opens (Start or click): its facts, its address, **what it contains** (archive listed on opening) and **the game** it most likely belongs to (the waiting list game that received it or one of whose items comes from the same page, otherwise the installed table whose title is in its name).
  Actions: **"Ajouter à <table>"** (Add to <table>: add plan targeting this table, the file stays where it is; a waiting list file "to install" is then marked installed), **"Ajouter à un autre jeu…"** (Add to another game…: any installed table, or any waiting list game, in the part the content says; unreadable content: "Quelle partie ?", Which part?), **"Installer comme nouvelle table"** (Install as a new table: when it contains a `.vpx`, or when we cannot tell) and "Mettre à la corbeille" (Move to the trash).
  "Afficher Téléchargements de Windows" (Show Windows Downloads) adds the last month's files from that folder, without opening File Explorer.
  **"Tout vider" (Empty all)** moves the whole area (never Windows Downloads) to the Cyber Pinball trash (`<racine>\trash\<date> Téléchargements`), after a confirmation whose cursor is on "Annuler" (Cancel) and which says what the waiting list loses: an item received but not installed is awaited again, a file kept aside is forgotten; an installed table no longer needs its file.
- **File picker**: wherever a file or folder is chosen on the PC (the "Ajouter une table" funnel, the path's "J'ai déjà le fichier" (I already have the file), the ROM library's "Ajouter" (Add), a media item's "Choisir un fichier…" (Choose a file…), "Chercher ailleurs…" (Look elsewhere…) to replace a waiting-list file, another frontend's folder for the media takeover), Cyber Pinball opens its own screen instead of the Windows dialog box, which opened on the main screen and could not be driven with the buttons.
  It shows where you are, with the flippers (choose), Start (open a folder, tick a file, or take it when only one is expected), Exit (parent folder, then cancel), the mouse (click, drag a file onto the window) and the keyboard (Tab, Enter, Esc).
  **Places**: Cyber Pinball's downloads (opened by default when they have what is wanted, with each file's origin and use), Windows Downloads, the import folder, the Desktop, then USB drives and disks (`Get-CimInstance Win32_LogicalDisk`, read again every 15 seconds: a plugged-in drive appears at the next opening).
  The content is **filtered** on what the screen expects ("Filtre : Fronton (.mp4, .png…)"); other files are counted, and "Afficher tous les fichiers" (Show all files) shows them, marked "Ne convient pas" (Does not fit).
  Several files can be ticked across folders ("Prendre les 2 fichiers choisis", Take the 2 chosen files); "Prendre ce dossier entier" (Take this whole folder) takes the open folder.
  Distinct states: empty folder, no fitting file, drive removed or access denied ("Réessayer", Try again).
  A file reused from the downloads area is noted in the log.
  On a desktop, three columns (places, content, moves); on the cabinet (portrait, rotated playfield), places as chips three across, then the content, then the moves in two columns.
  Cancelling brings back the screen you came from, cursor included.
- **Invariant**: a test (`packages/core/src/test/downloads.test.ts`) refuses any `showOpenDialog` or `showSaveDialog` in `app/src`.
- **Code**: `packages/core/src/downloads.ts` (inventory, origin, link to the waiting list, to site records and to the VPinMediaDB index, log, trash) and `packages/core/src/filepicker.ts` (places, drives, filters, folder content, going up), tests in `packages/core/src/test/downloads.test.ts`; screens in `app/src/downloads-screen.ts` and `app/src/file-picker.ts` (`lib-picker` and `lib-downloads` layout, `app/renderer/library.css`).
  Mock-ups: design system, "Téléchargements, borne" and "Sélecteur de fichiers, bureau / borne".
