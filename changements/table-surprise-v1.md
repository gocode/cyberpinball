# Table surprise / Surprise table

## Français

- Maintenir les deux flippers dans la roue tire une table autorisée de la collection active, avec une loterie de logos sur le plateau et lancement par le mécanisme habituel après relâchement.
- Les confirmations locales de contenu et de disponibilité excluent les entrées inconnues, adultes ou masquées ; le mode invité et les MagnaSave gardent leur priorité. Exit annule et une réservation commune empêche les doubles lancements.

## English

- Holding both flippers on the wheel draws a permitted table from the active collection, with a logo lottery on the playfield and the existing launcher starting the game after release.
- Local content and availability confirmations exclude unknown, adult or hidden entries; guest mode and MagnaSave retain priority. Exit cancels and a shared reservation prevents duplicate launches.
